# Sentinel V26

Instalación y guía completa: abre [README.md](README.md).

1. Haz doble clic en `Iniciar_Sentinel.cmd`. La primera vez se abre un asistente para guardar el token sin mostrarlo.
2. Sentinel instalará sus dependencias al primer inicio. Luego abre http://localhost:5000.
3. Para cambiar el token, usa `Configurar_Sentinel.cmd`.
4. Para probar sin conectarte a Discord, usa `Ver_Panel_Demo.cmd` y abre http://localhost:5001.

Se requiere Windows y Python 3.12. El primer inicio instala las dependencias en `.venv`.
Guía detallada paso a paso: docs/INSTALACION_WINDOWS.md
